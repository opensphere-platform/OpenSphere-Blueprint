# Backbone 설계·구현·운영 대장

기준일: **2026-11-17 KST**. 작성: Jupiter. 목적: 다음 작업자가 실제 Backbone의 책임·계약·소스·배포 상태를 구별하고 이어받을 수 있도록 한다.

이 묶음은 **상세 설명과 사실 대장**이다. D-번호를 추가하거나 기존 결정·권한을 변경하지 않는다. 새 구조·기능·정책 예외의 승인도 아니다.

## 읽는 순서

1. [상세 설계](DESIGN.md): 위치, 구성요소, 신원·실행·저장·업데이트·복구 계약.
2. [실제 구현·운영 현황](IMPLEMENTATION-STATUS.md): 배포됨 / 소스만 / 격리 검증 / 미완료를 구별.
3. [작업·배포·검증 이력](DELIVERY-HISTORY.md): 과거 개발 실증부터 현재 RKE2 적용과 PG 전환 보류까지.
4. [Nexus 감사 후속](AUDIT-FOLLOWUP.md): 원 감사 17건의 조치 범위와 남은 위험. 원 감사 폐기·전체 종결 아님.
5. [근거 대장](evidence-index.json): 확인한 소스·검증 파일의 SHA256, 요약의 출처, 최신 읽기 전용 관측.

## 기준과 정본

- 상위 개념: [네 면 구조](../overview/FOUR-PLANES.md), [용어](../overview/GLOSSARY.md), [결정 대장](../architecture/OPENSPHERE-LAYER-BASELINE-v0.2.md). D-86까지의 정의·제안 구분을 유지한다.
- Backbone 소스/계약 정본: DevOps의 `Projects/OpenSphere/OpenSphere-Backbone` 저장소. 대응 구현은 Gitea 보호된 PR·CI·main으로 관리한다.
- Backbone main 확인 기준: `f04476ebfc932c324ff4fc40db3f55cd17f3ba39`. 실제 운영 Console은 이 main 전체를 설치한 것이 아니라 아래의 승인된 구성요소 조합이다.
- 운영 반영 기준: **Setup 0.6.0-edge.52 / Console 26.1117.1110.21**의 수용 기록. 문서 작성 중 운영 Deployment의 이미지·ready replica도 다시 조회했다. 현재 관측은 전 기능 업무 검수나 과거 전 시험 재실행이 아니다.
- PG 후보: PR23 `c7c60d6ddf166ef95de7595112dea105f12ea52d`, 필수 CI86 실패. **운영 PG 전환·저장 선택 미실행**. 229개 소스 검사가 필수 CI 실패를 덮지 않는다.
- Blueprint는 공개 저장소다. 비밀값, 사용자/장치 식별자, 내부 접속 주소, kubeconfig, 복구 키, 원본 운영 로그는 싣지 않는다. 근거 파일 이름·SHA는 원본 대조용이며 비밀 원본의 공개 링크가 아니다.

## 증거 수준 표기

| 표기 | 의미 | 의미하지 않는 것 |
|---|---|---|
| 결정 | D-대장/명시 승인으로 채택된 원칙 | 구현·배포 완료 |
| 제안 | 설명·보완·미래 계약 | 자동 정책·구현 승인 |
| 소스 구현 | 특정 SHA에 코드 존재 | 배포·실행 성공 |
| 격리 실증 | 명시한 시험 입력/환경에서 관측 | 전체 upstream 적합성·운영 성능 |
| 운영 반영 | 고정 산출물·설치 원장·사후 확인 | 모든 업무 경로 검수 |
| 미완료/보류 | 남은 관문·결정권자·재개 조건 존재 | 팀장이 임의로 포기·승인한 것 |

역사 문서의 localhost/과거 버전/“진행 중” 표기는 당시 기록이다. **삭제된 localhost RKE2를 복구하거나 과거 매니페스트를 현재 설치에 재적용하지 않는다.** 새 통합 개발·시험은 운영 RKE2의 격리된 자원으로 한다. 기존 서비스·데이터·권한과 시험용 계정·Secret·namespace를 분리한다.

## 갱신 규칙

- 코드 병합, 이미지 발행, 설치 반영, 실제 사용, 복구 검증을 따로 기록한다.
- 요청 → 커밋/PR → 필수 CI → 불변 산출물 → 업데이트 → 효과/보존 결과를 연결한다.
- 실패·대체 버전·미실행 작업을 지우지 않는다. 원 감사는 유지하고 후속 판정으로 연결한다.
- 설명을 바꾸면서 D-대장이나 운영 권한·프로필을 자동 변경하지 않는다.
- 지문·메타데이터·Pod Ready·UI 항목 수를 보안 통제나 자가 운영 완료 증거로 바꾸지 않는다.
