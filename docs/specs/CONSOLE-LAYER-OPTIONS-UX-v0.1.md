# 레이어 구성 화면 — 서랍 · 사용자 이름 · 드래그 순서 · Carbon 아이콘 라이브러리(v0.1)

**상태:** 소유자 결정(2026-11-23, D-93). D-87 · D-89 · D-90의 개정이다. 구현은 Codex, 검수 · 운영 반영 · 전체 진행은 Claude가 한다.
**작성:** 2026-11-23 · Claude
**소유자 지시(원문):**
> icon 표시는 https://www.carbondesignsystem.com/building-blocks/foundations/icons/library 같이 처리 해줘
> /#/configuration/osr/layers 에서 각 레이어 구성(옵션)은 우측 서랍 페이지로 처리 할것
> 레이어 구성에서 각 레이어의 커스텀 이름을 설정 할 수 있게 하고, 리스트서 순서를 드레그로 이동하면 메뉴 구조도 그 순서를 받아 표현 되도록 한다.

## 1. 바뀌는 결정

| 이전 | 이후(D-93) |
|---|---|
| D-87 ①: 레일 순서 고정(HISS · Fabric · …) | **기본 순서**일 뿐이다. 관리자가 레이어 목록에서 드래그로 바꾸면 레일 순서가 따라간다 |
| D-89 §6 · D-90: 관리자는 이름을 바꾸지 않는다 | 관리자가 레이어의 **표시 이름**을 정할 수 있다. 레이어 id · 주소(`#/<section>`) · 판정 · 권한은 바뀌지 않는다 |
| D-90: 레이어 옵션은 레이어 세부 화면 안에 그린다 | 레이어 목록에서 여는 **오른쪽 서랍(side panel)**에 그린다 |
| LM3: 아이콘 선택은 검색 + 최대 300개 격자 | **Carbon 아이콘 라이브러리 페이지와 같은 방식**으로 보인다(§4) |

**바뀌지 않는 것**
- 레이어를 만들거나 지우지 않는다.
- 패키지는 자기 레이어에만 메뉴를 낸다.
- 옵션은 설치 판정 · 권한을 우회하지 않는다.
- 숨김은 보안 경계가 아니다.

## 2. 레이어 목록(`#/configuration/osr/layers`)

- 행마다 아이콘 · 표시 이름(사용자 이름이 있으면 그것, 아래에 작게 원래 이름) · 설치 · 갱신 · 상태 · 설치 허용 · **"구성"** 버튼이 있다.
- **드래그로 순서를 바꾼다.**
  - 행 왼쪽에 끌기 손잡이(Carbon `draggable` 아이콘)가 있다.
  - 끌어 놓으면 화면 아래에 "순서 저장" 막대가 나온다(사유 입력 + 저장 · 되돌리기). 저장하면 원장에 남는다.
  - **키보드 대체 수단이 반드시 있다:** 손잡이에 초점을 두고 위 · 아래 화살표로 이동하거나, "위로 · 아래로" 단추를 둔다. 스크린 리더에 "n번째로 옮김"을 알린다.
- 저장한 순서는 다음에 그대로 쓰인다.
  - 레일의 레이어 순서
  - 레이어 목록 자체의 순서
  - 스토어의 레이어 묶음 순서
- Backbone(설정)은 순서와 이름 변경 대상이 아니다. 레일 맨 아래 톱니바퀴 자리에 그대로 있다.
- 행을 누르면 지금처럼 레이어 세부 화면으로 간다. 옵션 편집은 세부 화면이 아니라 서랍에서만 한다.

## 3. 레이어 구성 서랍

- "구성"을 누르면 **오른쪽 서랍**이 열린다. Carbon side panel이고, 이미 쓰는 `osc-otp-confirm` 패널과 같은 계열이다. 크기는 넓게(lg 이상) 한다.
- 서랍 제목: "<표시 이름> 레이어 구성"
- 서랍 안의 구역(위에서 아래로)

| 구역 | 내용 |
|---|---|
| 표시 이름 | 글상자 하나. 비우면 기본 이름. 1~30자, 글자만(제어 문자 · HTML 없음), 앞뒤 공백 제거. 옆에 원래 이름을 보인다 |
| 아이콘 | 지금 아이콘 미리보기 + "아이콘 선택" 단추. 누르면 서랍 안이 §4의 아이콘 라이브러리 화면으로 바뀐다(뒤로 단추로 돌아옴) |
| 표시와 설치 | 레일에 표시, 스토어 설치 · 갱신 허용(바꾸면 MFA, 지금과 같음) |
| 메뉴 순서 · 숨김 | 묶음별 메뉴 항목. **같은 드래그 방식**(손잡이 + 키보드 대체)으로 순서를 바꾸고, 숨김 체크를 둔다. 묶음별 기본값 복원 |
| 변경 사유 · 저장 | 사유(필수) · "구성 저장" · "취소" |

- 저장하지 않고 닫으면 "저장하지 않은 변경이 있습니다" 확인을 띄운다.
- 저장하면 서랍을 닫고 목록 · 레일 · 섹션 화면이 새 값으로 다시 그려진다.
- 판 충돌(다른 관리자가 먼저 바꿈)이면 서랍 안에서 알리고 다시 읽게 한다.

## 4. 아이콘 라이브러리 화면(Carbon 공식 페이지와 같은 방식)

기준 페이지: https://www.carbondesignsystem.com/building-blocks/foundations/icons/library

2026-11-23에 Claude가 이 페이지를 직접 열어 확인한 구성은 다음과 같다. 이 구성을 그대로 따른다.

| 요소 | 기준 페이지 | OpenSphere에서 |
|---|---|---|
| 검색 | 위쪽 왼쪽 큰 검색창, 자리 표시 "Search icons", 지우기(×) 단추 | 같은 자리 · 같은 모양(Carbon Search lg). 자리 표시 "아이콘 검색". 이름 · 표시 이름 · 별칭으로 찾는다 |
| 분류 | 검색창 오른쪽에 붙은 드롭다운. 기본 "All icons", 목록 AI · Alphanumeric · App catalogue · Commerce · Controls · Data · File · Formatting · Health · IBM · Instruments · Navigation · Operations · Research · Senses · Social · Status · Systems · Technology · Third-party logos · Time · Toggle · Travel · User · Weather | 같은 자리 · 같은 모양(Carbon Dropdown). 기본 "모든 아이콘". 목록은 번들된 `@carbon/icons/metadata.json`의 `categories[].subcategories[].name`에서 만든다(사이트와 같은 분류 이름) |
| 격자 | 분류마다 큰 제목(예: "AI") 아래 정사각 타일 격자. 넓은 화면에서 한 줄에 6개, 타일 약 150px, 1px 경계선으로 붙은 격자 | 같다. 분류 제목 + 정사각 타일 격자. 서랍 폭에 맞게 한 줄 개수를 줄인다(서랍에서 3~4개, 좁은 화면 2개) |
| 타일 | 왼쪽 위에 아이콘 표시 이름(작은 글씨), 가운데에 아이콘(약 32px) | 같다. 아이콘은 빌드에 넣은 정적 SVG를 `<img>`로 그린다(지금 방식 유지) |
| 마우스를 올리면 | 타일 오른쪽 아래에 작은 아이콘 단추 둘(SVG 내려받기, 코드 복사)과 툴팁 | 내려받기 · 코드 복사는 넣지 않는다. 대신 **누르면 선택**이다. 마우스를 올리면 배경이 바뀌고, 오른쪽 아래에 "선택" 아이콘이 나온다 |
| 선택 표시 | — | 지금 선택한 타일에 파란 테두리와 체크 표시. 위쪽에 "선택한 아이콘: <표시 이름>" 요약과 "기본 아이콘으로" 단추 |
| 결과 없음 | "No icons match the selected search criteria." | "검색 조건에 맞는 아이콘이 없습니다." |
| 성능 | 페이지 전체 렌더링 | 아이콘이 2,641개이므로 화면에 보이는 분류 · 줄만 그린다(가상 스크롤 또는 점진 렌더링). 처음 열 때 멈춤이 없어야 한다 |
| 키보드 | — | 검색창 → 분류 → 격자 순 초점. 격자는 화살표로 이동, Enter · Space로 선택. 타일마다 접근 가능한 이름(표시 이름) |

- 고를 수 있는 목록은 지금처럼 **빌드에 실제로 들어간 아이콘(catalog.json)**뿐이다. 서버도 저장할 때 같은 목록과 대조한다(LM3 그대로).
- 레일 · 섹션 홈 · 레이어 목록 · 서랍 미리보기는 같은 아이콘을 쓴다.

## 5. 저장

- 레이어 설정(`osr.layer_settings`)에 **`label`**(표시 이름, 빈 값이면 기본)을 더한다.
- **순서는 레이어 하나의 값이 아니라 전체 목록 하나**다. 다음을 지킨다.
  - 원자적으로 저장한다. 판이 하나이고, 사유와 감사 기록이 남는다.
  - 판이 다르면 409를 돌려준다.
  - 레이어 넷이 빠짐없이 한 번씩 들어 있어야 한다.
  - 저장된 순서가 없으면 D-87의 기본 순서를 쓴다.
- 표시 이름 · 순서 · 아이콘 · 메뉴는 MFA 없이 바꾼다(사유 필수). 설치 허용만 MFA다.
- 원장 이행은 새 번호(024 이후)로 낸다. 기존 쓰기 함수의 허용 키를 넓히고, 순서용 함수 또는 표를 둔다. 이행은 격리 DB에서 리허설한다.
- `GET /console-api/navigation`이 레이어 표시 이름 · 순서를 함께 돌려준다. 그래서 레일이 Console 재빌드 없이 따라간다.

## 6. 표시 이름이 쓰이는 곳

레일(글자 · 툴팁), 보조 탐색 머리, 섹션 홈 제목 · 이동 경로, 레이어 목록 · 세부 · 서랍 제목, 스토어의 레이어 묶음 제목. 문서 · 계약 · 주소 · 원장의 레이어 id는 그대로다.

## 7. 구현 단위와 합격 기준

| 단위 | 범위 | 합격 기준 |
|---|---|---|
| **UX1 서랍 · 이름 · 드래그 순서** | §2 · §3 · §5 · §6(아이콘 선택 화면은 지금 것을 서랍 안으로 옮김) | 레이어 목록 드래그 → 저장 → 레일 · 스토어 순서가 Console 재빌드 없이 바뀐다. 키보드만으로 순서를 바꿀 수 있다. 표시 이름이 §6의 모든 곳에 보이고 주소는 그대로다. 판 충돌 409. 이행 024 리허설. Rust 단위 시험(이름 형식, 순서 목록 완전성, 판) 포함 |
| **UX2 Carbon 아이콘 라이브러리 화면** | §4 | 기준 페이지와 같은 구성(검색 + 분류 드롭다운, 분류 제목별 정사각 타일, 타일 왼쪽 위 이름 · 가운데 아이콘)이다. 분류는 메타데이터의 하위 분류 이름이다. 2,641개를 열어도 멈춤이 없다. 키보드 선택이 된다. 결과 없음 문구가 있다. 1440 · 390 px와 서랍 안 캡처를 PR에 남긴다 |

**모든 단위에 공통**
- 운영에 반영하지 않는다. 격리 설치본 · 시험 DB까지만 다룬다.
- 앞 단위 PR이 병합된 뒤 main 기준으로 연다.
- 드래그는 새 라이브러리를 들이든 표준 HTML 드래그를 쓰든 정할 수 있다. 라이브러리를 들이면 의존성 정책 검사를 통과해야 한다.
